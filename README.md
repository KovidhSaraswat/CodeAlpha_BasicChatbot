# 🤖 Basic Rule-Based Chatbot

A simple terminal-based conversational agent built with Python. Developed as part of the **CodeAlpha Python Programming Internship**[cite: 1, 3].

---

## 📌 Project Overview
This project demonstrates a rule-based AI chatbot capable of understanding user inputs and delivering context-aware responses using custom text processing and pattern matching[cite: 1].

### Key Features
* 💬 **Interactive Conversation Loop**: Continuous execution until the user exits using exit keywords[cite: 1].
* 🧹 **Text Normalization**: Strips extra whitespace and converts inputs to lowercase to improve keyword matching.
* 🛑 **Fallback Mechanisms**: Handles unrecognized user statements gracefully.

---

## 🛠️ Tech Stack & Concepts Used
* **Language**: Python 3.x[cite: 1, 3]
* **Core Concepts**: `if-elif-else` logic, string manipulation methods, functions, control loops[cite: 1].
